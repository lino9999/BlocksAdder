# Development verification

The reports on this page concern 1.1.0-SNAPSHOT development artifacts. The published 1.0.0 prerelease and its historical verification report are unchanged.

The frozen combined artifact `ec0c34acfcbc851c6f286c3cba9ebc525eea35685ca38c0df8d84f69dab8ac4f` passed eighteen complete server processes, with a restart on each of nine builds: Spigot 1.21.11, 26.1.2, 26.2 and 26.3; Paper 1.21.11, 26.1.1, 26.1.2, 26.2 and 26.3. Java 21 ran 1.21.11; Java 25 ran 26.x. The executed checks cover core item/API/recipe/pack/HTTP/validation behavior and persistent world/helper lifecycle. Exact counts and server versions are in [development-core-matrix.json](development-core-matrix.json).

Separate actual protocol-player scenarios on Spigot and Paper 1.21.11 passed 141 assertions each on the same frozen artifact `71832cd7ea183869e27628d43b8da370afa64c6714976b0902e2a1af4d8363e0`. They exercise native digging and abort, tool/tier/durability rules, permission/protection, disguise visibility, HUD/resource-pack packets, vehicle driving and seats, fuel, movement/attack cancellation, dismount/removal, bone meal, original crop schemas and conditional harvesting. Additional checks cover transactional content administration, typed chest-NBT loot, original random-tick/weather/player-proximity growth, rectangular stage hitboxes, spacing, cached density and equipment asset generation. Neither endpoint emitted plugin event/packet exceptions in these runs. [development-verification.json](development-verification.json) retains candidate hashes and scoped results, including earlier 74/84/96/104-assertion runs.

The earlier artifact `5b219d5ed18b91aeb9aa176aba0ceb9dd5733945a8fc32c87eb796a092bf19a9` passed its 130 assertions on both endpoints but exposed a Paper sound-packet conversion exception outside those assertions. That run was not accepted as a clean combined result. Guarding unregistered custom sound wrappers fixed the defect; the 141-assertion runs above include that fix. A preceding development checkpoint also exposed a null empty-armor-slot snapshot, which was corrected before these accepted runs.

Separate typed-NBT probes passed 25 assertions each on Spigot 1.21.11 and Paper 26.3 using the appropriate official ProtocolLib platform artifacts. They cover all six original scalar predicate types, exact numeric type matching, missing fields, native tile metadata and conditional explosion loot. Their exact artifact and dependency hashes are retained in the same JSON report.

The later `71832cd7...` artifact also passed four core processes without ProtocolLib: two complete starts each on Spigot 1.21.11 and Paper 26.3, using Java 25. These cover core linkage, pack/HTTP/validation behavior and restart persistence. Paper emitted the previously recorded Windows OSHI/Perflib host warning before plugin work. A preceding Spigot Java 21 first process passed, but its second process crashed natively in `ntdll.dll` during a validation test; the Java 21 executable then returned OS Access denied. That failed restart is not counted as success. Its leftover intentionally invalid fixture was disabled before repeating both starts with the existing Java 25 runtime. No host security settings were changed. The accepted native-player scenarios above had already completed on Java 21.

Follow-up artifact `e21383f851e5403c8e504a0fcbfad747202d7d1e1ea00728f9a6d608810b5400` passed 142 assertions each on Spigot/Paper 1.21.11 using Java 25. It includes the corrected nullable stop-sound bridge and nested legacy FIRE sound normalization. The extra assertion verifies that normalization preserves an actual configuration section. The subsequent source checkpoint adds the unknown skeletal-emote fallback correction; its dedicated emote acceptance remains separate. Clean Maven packaging of commit `07f665f` succeeded with Java 25 and `--release 21`.

GitHub's [build of `07f665f`](https://github.com/lino9999/BlocksAdder/actions/runs/40180272052) also completed successfully for its Java 21/25 matrix. This confirms the source checkpoint compiles on both toolchains; it is separate from runtime and complete feature acceptance.

Placement-orientation candidate `dfc9e3408e79fb43fa1bacd5419b602db39ee24e4b5a31cd5474a6ecdcbd7f27` passed 146 assertions on each native-player endpoint, with Java 25. Added cases cover non-default faces, reload persistence, reading version-one records with an upward face and rejecting non-Cartesian faces before touching the world. No plugin event/packet exceptions appeared. Full process restart coverage for the new face format remains a separate requirement.

Subsystem guides retain their additional targeted evidence: [models](entity-models.md), [vehicles](vehicles.md), [native blocks](native-blocks.md), [liquids/fire](fluids-fire.md), [generation](world-generation.md), [recipes](recipes-parity.md), and [crops](crop-growth.md). Their isolated artifacts can differ from the combined candidate; a passing module test is not a full combined regression.

Visual checks belong to the user. These reports do not claim rendered appearance was reviewed by the agent or that complete functional parity has been achieved. Further source edits require verification appropriate to the change.

Temporary probes, servers and intermediate artifacts stay under ignored `.work/`. Prior automatic approval review rejected their cleanup. They are excluded from source control and releases; this report does not claim they were removed.
