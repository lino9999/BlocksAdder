# Development verification

The reports on this page concern 1.1.0-SNAPSHOT development artifacts. The published 1.0.0 prerelease and its historical verification report are unchanged.

Placed-plan candidate `94fc1e32508d83dff64c2ff697b611e438258b7d982484884b591d966883ae19` passed 78 mixed native/API checks on each Spigot/Paper 1.21.11 endpoint, Java 21, without ProtocolLib. New independent `world.use/remove/harvest` plans cover native block/furniture use and both ordinary/conditional crop harvest, cancellation, exact placement identity, preparation reentrancy, delayed source guards and callback tool replacement. The same JAR repeated 56 held-break and 86 plant-view assertions per fork, then passed all 405 core/bundle checks on nine builds: 845 scoped assertions overall. [Exact results](world-plans-verification.json) retain the development tool-wear failure and its fix; the [distribution audit](world-plans-audit.json) passed. These are mixed native/API/data cases, not 845 distinct native interactions or proof of complete parity. New native player behavior on 26.x remains open.
